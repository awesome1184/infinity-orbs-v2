## Important open findings / areas

- **User report (2026-10-10):** Shards awarded by rolls appear briefly, then the resource bar returns to zero. A client-side guard was committed in `ac0b525` to ignore a PlayerState response that claims the already-applied server revision but reports a different Shards balance. This protects the equal-revision stale/malformed-snapshot path; it is a **mitigation, not a verified root-cause reproduction**. No client/runtime test is available here; keep this report open until independently traced or reproduced.

A successful Reddit submission followed by local save failure can leave a post without a corresponding local cooldown/attribution update. Needs idempotent request receipt/recovery; don't solve by pretending external publishing and Redis can be atomic.
